Lightweight Session-Based Voting & Planning Tool
Architecture Assumptions and Design Notes
Purpose

Create a collaborative web application similar to BreadBox that emphasizes:

Zero-account onboarding
Fast session creation
Easy participant joining
Real-time collaboration
Resilience to refreshes and disconnects
Minimal user friction

This document captures architectural assumptions inferred from observing the BreadBox user experience and translates them into a design suitable for implementing a similar system.

UX Principles
Core Goals

A user should be able to:

Create a session in under 30 seconds.
Share a link with participants.
Have participants join without creating accounts.
Collaboratively vote, estimate, or prioritize.
Recover from refreshes and temporary disconnects.
Export results when finished.
Explicit Non-Goals
Long-term user profiles
Enterprise identity management
Persistent user workspaces
Complex permissions

The system is optimized for ad-hoc collaboration.

Design Summary

The ideal system is:

Plain Text
Accountless
Link-Based
Real-Time
Reconnect-Friendly
Host-Independent
Server-Persisted

Key principles:

Session owns the state.
Participants are identified by UUIDs.
Join links are the primary sharing mechanism.
Refreshes and disconnects should be invisible to users.
Session data is persisted server-side.
Lightweight collaboration is prioritized over strict security and identity management.
